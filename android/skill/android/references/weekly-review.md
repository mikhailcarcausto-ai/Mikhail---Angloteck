# Playbook — Weekly Review & Shutdown Rituals

## Thursday: report cut-off (work)
Run `cp-process-tracking.md` → weekly update procedure. Output: change list + alerts +
draft comments, ready for `vNN+1`.

## Friday: weekly review (15 min, 16:00)
```
📊 Semana <dd-mmm> – <dd-mmm>

✅ Cerrado esta semana        (hitos con Actual, documentos firmados)
🔴 Se movió / atrasado        (proceso · hito · Δ vs semana pasada · causa)
🤝 Compromisos abiertos       (persona · qué · fecha)
📅 Próxima semana: top 5      (por consecuencia)
🧹 Orden                      (archivos duplicados/versiones viejas a archivar, borradores sin enviar)
❤️ Para ti                    (plan del fin de semana, fecha especial, descanso)
```
Then the memory tidy (see `memory-protocol.md`).

## Daily shutdown (on "cierro por hoy" / "end of day")
1. What got done (3 bullets max).
2. What's carried to tomorrow, and the **first task for tomorrow morning**.
3. Any message that must go out tonight? (draft it or consciously defer it.)
4. A short, warm close: "Listo. Desconéctate, que mañana arrancamos con <X>. ❤️"

## Drive hygiene (monthly or when noticed)
Flag lock files (`~$…`), stray logs, and multiple copies of the same version
(`v39 (1)`, `v39 (2)`, …). Propose a move to an `_archivo/` folder; never delete without
approval.
